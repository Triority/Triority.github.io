# 设计思路
ModuHF 是一个面向学习和实验的模块化短波业余无线电台项目。项目目标不是一次性做出一台完整成品电台，而是从最基础的射频处理电路开始，将短波电台拆分为若干可以独立测试、替换和升级的功能模块，逐步构建出完整的接收、发射、数字信号处理和功率放大系统。

项目第一阶段从 28 MHz 单波段 SSB 接收机 开始。选择 28 MHz 的原因是该频段便于进行短波传播、SSB、FM、FT8 和 QRP 实验，同时电路复杂度仍然可控。接收机采用 I/Q 直接变频架构：天线信号首先经过 28 MHz 带通滤波器，滤除带外干扰；随后由 Si5351 和 74AC74/74ACT74 产生四相本振信号，驱动 SN74CBT3253 构成的 Tayloe I/Q 混频器，将 28 MHz 射频信号转换为 I/Q 音频基带；最后通过 OPA1678 等低噪声音频运放完成差分放大、滤波和电平调整，并输出到声卡或音频 Codec，由 PC 或后续 MCU/DSP 完成 SSB 解调、频谱显示和音频输出。

整个系统按照模块化思路设计，每个模块都具有清晰的输入、输出和测试方法。例如，带通滤波模块可以通过 NanoVNA 单独测量 S21、S11 和通带位置；本振模块可以单独验证 4 倍频率输出和四相分频关系；I/Q 混频模块可以通过输入 LO ± 1 kHz 的测试信号观察正交音频输出；音频放大模块则可以单独输入已知音频信号，验证增益、滤波和声卡电平匹配。通过这种方式，整个项目可以逐级验证，避免一次性集成带来的调试困难。

在接收链路跑通之后，项目将扩展到毫瓦级 I/Q 发射。发射部分采用与接收机相对应的 QSE 架构，由 PC 或 MCU 生成 I/Q 基带信号，通过声卡或 Codec 输出，再经过 I/Q 音频调理、SN74CBT3253 开关调制、28 MHz 带通滤波、MMIC 小信号缓冲和低通滤波，得到 0 dBm 到 +10 dBm 级别的干净射频输出。该阶段重点不是追求功率，而是学习载波泄漏、镜像边带、I/Q 平衡、杂散和谐波控制。

后续阶段将逐步加入更多模块，包括多波段输入带通滤波器、可旁路 RF LNA、功率检测、SWR 检测、收发切换、毫瓦级到瓦级驱动级、5W/20W 线性功放以及输出低通滤波器组。

ModuHF 的核心理念是：把短波电台拆成可以理解、可以测量、可以替换的模块。每一步都围绕一个明确的问题展开：信号从哪里来、经过什么处理、输出应该是什么、如何验证它是否正确。通过这种方式，项目不仅可以最终形成一台可扩展的 QRP/短波 SDR 电台，也可以作为系统学习射频电路、I/Q 信号处理、SDR 软件、音频 DSP 和功率放大的长期实验平台。
