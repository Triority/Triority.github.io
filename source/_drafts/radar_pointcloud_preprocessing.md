# 概述
毫米波雷达的点云较为稀疏，且由于多径反射等原因噪声较大。为了改善这一现象设计一个模型对毫米波雷达的点进行分类，分离出其中的噪声点。

训练数据将使用固态激光雷达和毫米波雷达对同一片区域进行探测，将其中重合的位置标记为真实点，距离较远的标记为噪声点，以此制作数据集进行训练。

# 数据准备
## ros bag保存
将固态激光雷达和毫米波雷达固定在一起，朝向同一个方向，进行数据采集并保存为ros bag
